# DarkMSAL — Чистовик (Production Clean Distribution)

Полный, автономный и очищенный от устаревших артефактов дистрибутив клиентского приложения для студентов **МГЮА им. О.Е. Кутафина**.

Поддерживает единую кодовую базу для:
1. **Web (PWA / SPA)** — современное быстрое веб-приложение на React 18 + Vite + Tailwind CSS.
2. **Android (.apk)** — мобильное приложение на базе Capacitor 7.
3. **macOS (.dmg)** — десктопное приложение для Apple Silicon / Intel на базе Electron 44.
4. **Linux (.AppImage, .rpm)** — сборка под дистрибутивы Linux (включая Fedora).
5. **Windows (.exe / NSIS)** — установщик для Windows.

## 🚀 Команды для запуска и разработки

Все команды запускаются из корня проекта:

### Режим разработки (Web)
```bash
npm run dev
```
Открывает локальный dev-сервер по адресу `http://localhost:5173/`.

### Сборка Web-версии
```bash
npm run build
```
Компилирует оптимизированный production бандл в папку `dist/`.

### Просмотр собранной Web-версии
```bash
npm run preview
```

## 📦 Сборка релизов под платформы

### 1. Сборка под Android (APK)
```bash
npm run package:apk
```
*Результат*: готовый файл `release/DarkMSAL-1.1.apk`.

### 2. Сборка под macOS (DMG)
```bash
npm run package:mac
```
*Результат*: готовый файл образа диска `release/DarkMSAL-1.1.0-arm64.dmg`.

### 3. Сборка под Linux (Fedora / Ubuntu / Debian)
```bash
npm run package:linux
```
*Результат*: `.AppImage` (запускается на любом дистрибутиве) и `.rpm` (для Fedora/RHEL) в папке `release/`.

### 4. Сборка под Windows
```bash
npm run package:win
```
*Результат*: установщик `.exe` (NSIS) в папке `release/`.
