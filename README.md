# DarkMSAL 1.0 — Клиентское приложение для студентов МГЮА

> *«Для Альма-матер с любовью.»*

**DarkMSAL** — современное, быстрое и полностью автономное кроссплатформенное приложение для студентов и учащихся колледжа **Московского государственного юридического университета имени О.Е. Кутафина (МГЮА)**.

---

## ⚡ Ключевые возможности

- 🔒 **Zero-Proxy & Прямое TLS-соединение**: приложение работает напрямую с официальным сервером `lk.msal.ru:3443`. Никаких промежуточных прокси, сторонних бекендов и сбора телеметрии.
- 🛡️ **Локальное шифрование AES-GCM-256**: сессионные токены и учётные данные хранятся на устройстве в зашифрованном виде через аппаратный Web Crypto API. Полное соответствие 152-ФЗ РФ.
- ⚡ **Мгновенный холодный старт (0 мс)**: расписание на текущий день отображается сразу из кэша при входе, после чего фоново синхронизируется с сервером.
- 📅 **Расписание занятий**: удобный просмотр по неделям и месяцам, подсветка текущей пары, быстрый возврат к сегодняшнему дню, аудитории и ФИО преподавателей.
- 🎓 **Электронная зачётная книжка**:
  - Режим **«По семестрам»** (строго ограничен семестрами текущего учебного года).
  - Режим **«Вся зачётка»** с историей за весь период обучения.
  - Подгрузка дисциплин активной сессии, даты экзаменов/зачётов с обратным отсчётом дней.
- 📝 **Запись на отработки (консультации)**: просмотр доступных консультаций преподавателей кафедр и мгновенная запись/отмена записи в один клик.
- 📊 **БРС и Успеваемость**: модульно-рейтинговые баллы, средний балл, рейтинг студента и журнал пропусков.
- 🚀 **Автообновления через GitHub Releases**: встроенная система проверки новых версий из репозитория `Dewerro67/MSALKA` с уведомлением пользователя и скачиванием актуального пакета под используемую платформу.
- 🎨 **Адаптивный интерфейс**: поддержка системной тёмной и светлой темы, поддержка жеста Pull-to-Refresh на сенсорных экранах и мобильных устройствах.
- 🤖 **Поддержка и открытый исходный код**: ссылки на Telegram-бота поддержки (`@DarkMSAL_supportbot`) и исходный код прямо на главной странице.

## 📱 Поддерживаемые платформы

| Платформа | Формат сборки | Метод установки / распространения |
|:---|:---|:---|
| **iOS** | `.ipa` | AltStore, SideStore, TrollStore, Scarlet, direct sideload |

## 🛠️ Разработка и локальный запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки (Web)
```bash
npm run dev
```
Сервер разработки запустится по адресу: `http://localhost:5173`.

### 3. Запуск десктопной версии (Electron Dev)
```bash
npm run electron:dev
```

## 📦 Сборка дистрибутивов

### Сборка Web-версии
```bash
npm run build
```
Результат будет помещён в директорию `dist/`.

### Сборка под iOS (IPA)
```bash
npm run package:ipa
```
Результат: файл `release/DarkMSAL-1.0.ipa`, готовый для установки через AltStore / TrollStore / Scarlet.

### Сборка под Android (APK)
```bash
npm run package:apk
```
Результат: файл `release/DarkMSAL-1.0.apk`.

### Сборка под macOS (DMG)
```bash
npm run package:mac
```
Результат: образ диска `release/DarkMSAL-1.0.0-arm64.dmg` (или `-x64.dmg`).

### Сборка под Windows (EXE)
```bash
npm run package:win
```
Результат: установщик `release/DarkMSAL Setup 1.0.0.exe`.

### Сборка под Linux (AppImage, RPM, DEB)
```bash
npm run package:linux
```
Результат: бинарные пакеты в каталоге `release/`.
